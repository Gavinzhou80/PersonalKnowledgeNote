# Personal Knowledge Note：macOS 首版产品范围

> 文档状态：已确认，首版范围已冻结  
> 更新日期：2026-08-03  
> 开发约束：1 名开发者，6 个月，仅支持 macOS；核心链路质量优先于固定日期交付

## 1. 产品定位

Personal Knowledge Note 首版定位为：

> 面向需要长期阅读英文论文、技术文章和 PDF 的研究者、研究生及技术从业者，以“导入文档 → 阅读与翻译 → 划线摘录 → 结构化笔记 → 知识日志”为核心闭环的本地优先知识阅读工具。

首版不是通用日记、任务管理、自由白板、多人协作或完整文献管理软件。

## 2. 首版核心原则

1. **仅支持 macOS**：以 Apple Silicon Mac（M1 或更新、8 GB 内存）为基准，不承诺 Intel Mac 的性能与兼容性。
2. **本地优先**：文档、标记、笔记、日志和翻译缓存以本机数据为权威来源。
3. **云端 AI 按需参与**：阅读、标记、笔记、搜索和日志在离线状态下仍可使用；新的翻译与 AI 生成任务需要联网。
4. **来源可追溯**：每条摘录和笔记都能跳回原文位置。
5. **原文不可被译文替代**：译文可以修订或重新生成，原文始终作为权威引用来源。
6. **自动收集、人工确认**：划线可自动形成未整理摘录，但不会直接变成正式知识卡片。
7. **首版范围冻结**：知识聚类、记忆复习等能力只预留架构，不在六个月首版完整实现。
8. **质量优先**：如果开发周期仍然不足，应延期或削减次要功能，不牺牲标记定位、数据可靠性、翻译缓存和双语定位质量。

## 3. 平台与总体界面

### 3.1 三栏工作台

- 左栏：文件夹树、文档列表和智能入口。
- 中栏：网页、PDF 或双语阅读视图。
- 右栏：文章目录骨架及其章节下的摘录和笔记块。
- 左右栏均可折叠，并记住用户调整后的宽度。
- 提供专注阅读模式。
- 小窗口优先隐藏左栏，右栏可切换为抽屉。

### 3.2 文档标签页

- 支持同时打开多篇文档并通过标签页切换。
- 每个标签页保存阅读位置、缩放比例和阅读模式。
- 关闭应用后恢复上次阅读现场。
- 同一时刻只完整渲染当前文档；最近使用的少量文档可保留热状态。
- 跨文档对照时最多同时显示两篇不同文档。

### 3.3 键盘与鼠标

- 鼠标可完成全部核心操作。
- 支持切换三栏焦点、搜索、打开文档、划线、添加批注和创建摘录等快捷键。
- 首版提供快捷键说明，但不承诺完整的自定义改键系统。

## 4. 本地知识库与文档管理

### 4.1 单一本地知识库

- 首版仅维护一个本地知识库。
- 用户通过顶层文件夹和项目管理文档。
- 文件夹负责文档收纳；知识主题不与文件夹层级强绑定。
- 支持“全部文档”“知识日志”“待整理摘录”“收藏”等智能入口。

### 4.2 PDF 托管

- 导入 PDF 时默认复制到应用管理的本地资料库。
- 原始文件保持不变。
- 用户移动或删除下载目录中的原文件，不影响知识库副本。
- 通过文件哈希识别明显重复的 PDF。
- 支持在 Finder 中显示托管文件和导出原文件。

### 4.3 删除与恢复

- 文档删除后先进入回收站，不立即永久删除。
- 文档的划线和阅读笔记随文档保留，可整体恢复。
- 引用该文档的未来知识卡片不做级联删除。
- 只有用户明确清空回收站后才永久删除。

## 5. 第一阶段：网页文章闭环

### 5.1 URL 导入

- 用户输入公开可访问的文章 URL。
- 首版正式支持无需登录、订阅或付费墙即可访问的网页。
- 登录态、验证码、强反爬和付费墙内容不保证导入。
- 同一 URL 重复导入时提示已有文档。

### 5.2 本地静态阅读副本

- 提取标题、作者、日期、正文、图片和标题层级。
- 移除广告、导航、脚本、表单和追踪代码。
- 将正文和图片保存到本地，断网后仍可阅读。
- 使用本地 HTML 渲染，不保留评论、登录、播放器等动态交互。
- 外部链接交给默认浏览器打开。
- 不检测或处理来源网页后续内容变化。

### 5.3 网页目录与标记

- 根据标题层级生成文章目录。
- 点击目录节点跳转到对应正文位置。
- 支持文本选择、语义划线、批注和复制。
- 普通复制不自动生成笔记。
- 关闭并重新打开后，标记能准确恢复。

### 5.4 网页阶段验收门槛

- 成功保存正文、图片和目录，并可离线重新打开。
- 目录、阅读位置、划线和笔记在重启后恢复。
- 点击右侧摘录能跳回准确原文位置。
- 移动或删除笔记块不会破坏原文锚点。
- 日志能够记录当天的阅读、划线和笔记活动。
- Markdown 导出包含正文引用和来源 URL。

## 6. 第二阶段：中文 PDF 阅读闭环

### 6.1 PDF 范围

- 首版正式支持具有正常文本层的 PDF。
- 扫描版 PDF 可以导入和查看，但不承诺划线、翻译或 OCR。
- 加密、乱码字体和异常自由排版 PDF 不保证完整解析。

### 6.2 PDF 阅读

- 使用原生 PDF 阅读能力进行分页、缩放、搜索和选择文字。
- 支持 PDF 自带书签目录。
- 缺少目录时，可生成可编辑的候选目录。
- 保存页码、缩放比例和阅读位置。

### 6.3 PDF 标记

- 支持文字划线、批注和复制。
- 支持框选图片、表格、公式或任意页面区域，作为图片摘录进入笔记。
- 每条标记保存文档 ID、页码、页面坐标、引用文字和前后文。
- 点击右侧摘录能跳转到正确页码和区域。

### 6.4 PDF 阶段验收门槛

- 正常文本层 PDF 能够快速打开并稳定分页浏览。
- 目录书签或候选目录可正常导航。
- 文字标记和批注在重启后准确恢复。
- 区域截图摘录保留页码和坐标。
- 多标签切换后阅读位置、缩放和标记不丢失。
- 至少使用一篇约 50 页的双栏中文 PDF 验证坐标与性能。

## 7. 第三阶段：英文 PDF 多语言翻译闭环

### 7.1 语言识别与翻译启动

- 自动检测文档主要语言，并允许用户纠正。
- 系统不会自动开始全文翻译。
- 用户主动点击“进入翻译阅读”后，应用展示页数和任务规模，再由用户确认。
- 已完成翻译的文档直接从本地缓存加载。

### 7.2 多语言翻译

- 默认目标语言跟随 macOS 首选语言。
- 设置中可指定全局默认翻译目标语言。
- 每篇文档可以覆盖全局默认语言。
- 支持在模型能力范围内选择简体中文、繁体中文、日语、韩语、西班牙语等目标语言。
- 同一篇文档可保存多个目标语言版本，互不覆盖。
- 同一时刻译文 View 只显示一种目标语言，用户可以切换。

### 7.3 翻译模型分工

- 默认论文翻译模型：`qwen-mt-plus`。
- 快速或低成本翻译模式：`qwen-mt-flash`。
- DeepSeek 用于后续的概念解释、章节总结和知识整理，不作为默认论文翻译模型；相关功能是首版可选加分项，不属于发布门槛。
- 翻译能力通过独立的 `TranslationProvider` 抽象，不与通用聊天模型绑定。

详细模型调研见：[翻译模型与 API 调研](../research/translation-models-2026-08-03.md)。

### 7.4 翻译范围

- 只翻译自然语言正文、标题、图注和表注。
- 公式、变量、代码、DOI、URL 和引用编号保持原样。
- 图片按原文阅读顺序插入译文 View。
- 独立公式优先保留为原始视觉裁剪。
- 表格首版保留为图片，翻译表题和说明文字。
- 行内公式和引用使用受保护占位符，翻译后校验并恢复。

### 7.5 翻译缓存

- 翻译结果按文本块持续写入本地数据库。
- 缓存至少区分文档、原文块、原文哈希、源语言、目标语言、供应商、模型和配置版本。
- 第二次打开文档不重复请求已完成的翻译。
- 翻译中断后从尚未完成的文本块继续。
- 用户手动修订的译文具有保护状态，自动重翻不得覆盖。
- 只有用户明确执行“重新翻译本章”时才产生新版本。

### 7.6 双语阅读

- 原文保留 PDF 原始分页和版式。
- 译文采用连续、结构化的重排版式。
- 原文和译文通过稳定的文本块 ID 对齐。
- 支持原文在左、译文在右的双屏模式，分隔线可调整。
- 窄窗口下可以切换为原文／译文标签视图。
- 常规单栏和双栏论文提供段落级柔性同步。
- 复杂页面自动降级为页级同步，并允许用户手动校正对应关系。
- 用户正在操作的一侧作为同步主视图，避免两个滚动视图互相争抢。

### 7.7 双语标记

- 原文和译文中的划线属于同一条双语标记。
- 在任一侧划线，另一侧的对应文本块同步显示标记。
- 笔记保存原文、当前译文、来源位置和用户批注。
- 原文始终作为不可覆盖的权威引用。

### 7.8 翻译阶段验收门槛

- 正确识别主要语言并由用户主动启动翻译。
- Qwen-MT 按文本块翻译并持续缓存。
- 中断、断网或应用重启后能够继续任务。
- 图片、公式和表格按原文顺序出现在译文中。
- 常规双栏页面的阅读顺序和段落同步可用。
- 任一侧划线能够生成同一条双语摘录。
- 翻译失败、限流、超时和余额不足都有明确状态与重试操作。

## 8. 标记、摘录与右侧笔记

### 8.1 语义标记

- 黄色：重要内容。
- 蓝色：概念或定义。
- 红色：疑问或争议。
- 绿色：证据、案例或数据。
- 用户可以修改标记类型。

### 8.2 选中文本后的操作

- 复制。
- 划线并摘录。
- 添加批注。
- 翻译选中内容。
- DeepSeek 解释入口预留但默认隐藏，只有核心链路稳定且开发周期有余量时才启用。
- “创建知识卡片”仅预留入口，首版不完成卡片系统。

### 8.3 自动摘录

- 划线后立即在原文章节下形成“未整理摘录”。
- 自动保存引用文字、译文、页码或段落位置。
- 用户可以补充想法、移动、合并或删除摘录。
- 普通复制不会污染笔记区。

### 8.4 右侧目录与笔记结构

- 原文标题形成可折叠的目录骨架。
- 摘录和笔记块直接显示在对应章节下。
- 点击章节跳转正文。
- 点击笔记跳转具体划线位置。
- 支持“只看目录”“只看笔记”“全部显示”。

### 8.5 简化块式编辑器

- 使用原生块式编辑体验，不追求 Notion 级复杂富文本。
- 支持普通文本、标题、列表、引用、原文摘录、图片摘录和分隔线。
- 支持常用 Markdown 快捷输入。
- 支持新增、删除、缩进和上下移动块。
- 来源元数据与可编辑正文分离保存。
- 支持持续自动保存、撤销、重做和有限本地历史。

## 9. 知识日志初步框架

- 按日期自动汇总打开过的文档、阅读时长、划线和新增笔记。
- 展示当天新导入和完成翻译的文档。
- 用户可以编写当天总结、反思和后续阅读计划。
- 自动内容引用原始对象，不复制产生多个内容版本。
- 日志中的条目可以跳回文档和原文位置。
- 提供日历与日期列表浏览。
- 预留知识卡片数量、复习完成数和主题分布字段，但首版不启用完整功能。
- 不做情绪追踪、连续打卡和 AI 日报。

## 10. 搜索

### 10.1 首版实现

- 使用本地全文索引搜索文档标题、正文、译文、摘录和笔记。
- 搜索结果标明内容类型和所属文档。
- 点击结果跳转到具体文档与位置。
- 目标是在常规资料库中 1 秒内展示首批搜索结果。

### 10.2 首版不实现

- 语义搜索。
- 向量索引。
- 自动知识聚类。
- 基于相似度的跨文档知识发现。

## 11. 导出、备份与可靠性

### 11.1 导出

- 单篇阅读笔记可以导出为 Markdown。
- 摘录保留原文、译文、来源标题和定位信息。
- 暂不实现 Notion、Obsidian、Zotero 或 Anki 专用格式。

### 11.2 备份与恢复

- 支持完整知识库备份与恢复。
- 备份包含文档、图片、翻译缓存、标记、笔记和日志。
- AI 批量操作前创建可恢复点。

### 11.3 自动保存

- 划线、批注、移动块和目录调整立即写入本地。
- 应用异常退出后恢复到最近状态。
- 笔记保留有限的本地历史版本。

## 12. 国际化

### 12.1 首版界面语言

- 完整支持简体中文和英文界面。
- 默认跟随 macOS 首选语言。
- 设置中允许用户单独选择 App 界面语言。
- 不支持的界面语言回退到英文。

### 12.2 国际化结构

- 使用 Xcode String Catalog 管理本地化文案。
- 禁止在界面代码中硬编码用户可见字符串。
- 日期、数字、文件大小和复数采用 Locale 格式化。
- 界面语言、文档源语言和翻译目标语言相互独立。
- 用户笔记和日志内容不会因切换界面语言而自动翻译。

## 13. 设置与安全

- Qwen-MT 的 API Key 存入 macOS Keychain；如果启用可选的 DeepSeek 功能，其 API Key 同样存入 Keychain。
- AI 调用前明确提示将上传的正文范围。
- 本地知识库安全首版依赖 macOS FileVault，不自建整库加密。
- 支持配置默认翻译目标语言、模型、并发数和请求超时。
- 提供轻量 AI 任务中心，显示翻译任务的排队、执行、失败、暂停、取消和重试状态。
- 首版不建设账号、订阅、支付、云同步和运营后台。

## 14. 技术方向

- UI：SwiftUI，复杂控件通过 AppKit 补充。
- PDF：PDFKit。
- 网页：WKWebView + 正文清洗与本地静态 HTML。
- 简化块编辑：SwiftUI + `NSTextView` 封装。
- 数据库：SQLite + GRDB.swift。
- 全文搜索：SQLite FTS5。
- 网络与并发：URLSession + Swift Concurrency。
- 密钥：macOS Keychain。
- 日志：OSLog。
- 发布：Developer ID 签名、公证、DMG/ZIP 分发；后续使用 Sparkle 更新。
- 首版不进入 Mac App Store。

## 15. 建议开发顺序

### 里程碑 A：网页文章闭环

- 建立应用骨架、本地数据库和三栏界面。
- 完成 URL 导入、本地静态 HTML、目录、标记、右侧笔记和日志。
- 用一篇公开网页文章跑通完整闭环并达到网页验收门槛。

### 里程碑 B：中文 PDF 闭环

- 完成 PDF 渲染、目录、文字坐标锚点、区域截图和笔记跳转。
- 用一篇代表性中文双栏 PDF 达到 PDF 验收门槛。

### 里程碑 C：英文 PDF 翻译闭环

- 完成语言识别、Qwen-MT、多语言缓存、译文重排和双视图同步。
- 用一篇代表性英文双栏 PDF 跑通翻译闭环。

### 里程碑 D：产品加固

- 完成全文搜索、导出、备份、回收站、异常恢复和性能优化。
- 第一篇黄金文档跑通后，再建立 20～30 篇固定回归测试集。

## 16. 六个月首版明确不实现

- 扫描 PDF OCR 与复杂版面 OCR。
- 语义搜索和向量数据库。
- AI 自动知识聚类。
- 完整知识卡片库。
- FSRS 间隔重复复习系统。
- 可视化知识图谱。
- AI 自动建立知识关系和反向链接建议。
- 多设备同步和云端账户。
- 多人协作、分享和权限管理。
- Windows、Linux、iPhone 和 iPad 客户端。
- Zotero 级文献管理及 Word 引用插件。
- 通用知识库聊天助手。
- Notion 级富文本、数据库视图和自由布局。
- 需要登录、付费墙或浏览器 Cookie 的网页导入。
- 原网页更新检测及标记迁移。
- App 自建整库加密。
- Mac App Store 发布。

## 17. 首版成功标准

一名目标用户能够连续两周使用该 App 完成至少 5 篇英文论文的导入、翻译阅读、划线和笔记整理，并且无需回到其他工具补救核心流程。

同时满足：

- 标记在应用重启后不丢失，并能准确跳回原文。
- 双语同步对常规单栏和双栏论文可用。
- 一篇常规论文能够在数秒内开始阅读。
- 用户能在 30 秒内找到之前的一条摘录。
- 知识库能够完整备份并恢复。
- 至少 3 名内测用户愿意继续使用。

## 18. 已确认的范围决策

1. 开发周期由四个月调整为六个月；如果核心链路质量仍未达标，可以延期，不以牺牲数据可靠性和定位准确性换取固定日期交付。
2. PDF 区域截图摘录属于首版必需功能，但应在文字标记稳定后实现；首版不做表格识别和公式转换。
3. 完整知识库备份与恢复属于开始内测前的发布门槛。
4. 基础全文搜索属于首版发布门槛，必须覆盖标题、原文、译文、摘录和笔记，并支持跳回来源位置。
5. 保留最小回收站：支持软删除、恢复、永久删除及关联内容提示，不做自动清理和复杂保留策略。
6. DeepSeek 的解释与总结能力是可选加分项，不属于首版发布门槛；首版必须完成的是 Qwen-MT 翻译链路。
7. 首版核心功能范围正式冻结。新想法默认进入后续候选清单，除非它直接解决“导入 → 本地阅读 → 标记定位 → 结构化笔记 → 多语言翻译 → 日志 → 搜索与备份”链路中的阻断问题。
