# Web 导入手工验收清单（非自动化）

> 本清单**不得**接入 CI；所有自动化测试只允许访问本地 fixture 服务器。
> 对应产品范围：`docs/product/macos-v1-scope.md` §5.1 / §5.2 / §5.4。
> 每次发布前由人工逐项执行，结果记录在本文件底部的执行日志。

## 代表性 URL 矩阵

| 场景 | 代表性 URL 类型 | 验收要点 |
| --- | --- | --- |
| 静态文章 | 传统服务端渲染的博客/新闻页 | 正文、图片、目录完整保存 |
| 动态渲染 | SPA / 依赖 JS 渲染正文的页面 | 动态回退产出无 `<script>` 的离线副本 |
| 重定向链 | 短链服务（http → https → 最终页） | finalURL 正确，重定向 ≤ 10 跳 |
| 中文编码 | GBK/GB2312 声明的旧站 | 无乱码；issues 中出现 `webEncodingFallback` |
| 图片密集 | 多图长文（含超大图） | 超限/非法图片降级为 `webImageRejected`，不阻断导入 |
| 需认证/拒绝访问 | 返回 401/403 的页面 | 类型化失败（`accessDenied`），不产生半成品文档 |
| 无正文页面 | 登录墙/纯导航页 | 类型化失败 `webpageHasNoReadableArticle` |

## §5.4 验收门槛对照步骤

1. **保存与离线重开**：导入上表前两类 URL → 关闭应用 → 断网重开 → 文档可完整阅读。
2. **重启恢复**：导入进行中强杀应用并重启 → 任务从检查点续跑成功（或给出可重试的类型化失败）。
3. **阅读位置与标记**：阅读后滚动至中部、添加划线与笔记 → 重启 → 位置与标记恢复（阅读侧能力以 T06 阅读工作台现状为准，缺口另行立项）。
4. **摘录跳回**：点击右侧摘录能跳回准确原文位置（同上，锚点能力以 ADR-0002 现状为准）。
5. **日志与导出**：当日阅读/划线/笔记活动可被记录；Markdown 导出包含正文引用与来源 URL（若尚未实现，记为缺口）。
